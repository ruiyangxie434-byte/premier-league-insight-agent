# Matchup Lab

`v0.15.0` 新增 `/matchup` 页面与 `GET /api/form/matchup` 接口，用固定的
2024-25 英超完整赛果快照生成两队对阵简报。

## 输入

- `club_a`：球队 A 的 slug。
- `club_b`：球队 B 的 slug，必须与球队 A 不同。
- `season`：当前只接受 `2024-25`。

## 八个比较维度

1. 最终排名（越小越好）。
2. 赛季积分。
3. 赛季总进球。
4. 赛季总失球（越少越好）。
5. 19 个主场积分。
6. 19 个客场积分。
7. 按真实开球日期排序的末五场积分。
8. 最长连续不败场次。

每个维度都由后端确定性计算并返回 `club_a`、`club_b` 或 `even`，前端不自行
判断优势。接口同时从 380 场赛果中筛选两队本赛季的两次直接交锋，返回比分、
轮次、日期、胜者与两回合总比分。

## 结论边界

- 页面只复盘 2024-25 已完赛历史数据，不是实时状态。
- “占优维度更多”不等于未来胜率更高，也不生成预测比分。
- 完整赛果只有比分，不含控球率、xG、伤病、阵容或战术事件。
- StatsBomb 的单场历史事件样例属于 2003-04，不会混入本页计算。
- 来源、许可和固定提交见 [`DATA_SOURCES.md`](DATA_SOURCES.md)。

同一计算能力已注册为 League Copilot 的 `compare_clubs` 白名单工具；自然语言
问题只负责选择两支球队，所有维度、比分和边界仍由后端工具返回。

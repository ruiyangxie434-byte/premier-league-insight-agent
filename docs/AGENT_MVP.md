# Premier League Insight Agent · Hybrid Agent MVP

## 本阶段目标

把原来的英超数据展示平台升级为可以完成一条足球分析任务的垂直 Agent：

```text
用户任务
  → 识别两名球员和分析重点
  → 查询赛季数据
  → 统一换算每90分钟指标
  → 在 450+ 分钟合格球员池中计算百分位
  → 按任务动态加权
  → 输出证据、建议和结论边界
  → 千问增强表达或本地安全回退
```

## 为什么它不只是聊天框

Agent 的关键数值不是由自然语言模型猜测，而是由后端工具计算：

| 步骤 | 工具 | 责任 |
| --- | --- | --- |
| 1 | `intent_router` | 识别球员比较任务与分析重点 |
| 2 | `player_stats_query` | 从 SQLite 读取指定赛季记录 |
| 3 | `per90_calculator` | 换算每90分钟指标与合格球员池百分位 |
| 4 | `evidence_ranker` | 按任务权重排序证据并形成建议 |
| 5 | `qwen_grounded_narrative` / `local_narrative` | 基于既有证据组织最终回答 |

前端会把这五步执行轨迹直接展示出来，便于比赛评委检查“规划—工具调用—结果”
是否形成闭环。

## 当前能力边界

- 首页 Agent Notebook 当前只支持双球员比较；`/copilot` 在 v0.11.0 四工具基础上，已于 v0.13.0 加入受控相似球员检索。
- 当前球队范围为 2024-25 完整 20 队；球员快照包含 574 条球员—球队记录，Agent 固定使用其中 400 条 450+ 分钟记录，不是实时阵容数据库。
- 抢断和拦截只能作为防守参与度代理指标，不能完整代表真实压迫质量。
- League Copilot 中千问可以自主选择白名单函数，但参数与结果仍由后端校验和执行。
- 规则引擎保证离线演示稳定；Copilot 查询目前彼此独立，还不具备开放式连续对话记忆。

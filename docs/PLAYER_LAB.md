# Player Lab 数据、指标与百分位口径

## 功能范围

`v0.12.0` 将 `/players` 球员数据中心和 `/players/[slug]` 详情页扩展为 2024-25 英超全联赛历史快照：

```text
574 条球员—球队记录 → 搜索 / 筛选 / 排序 / 分页
                    ├→ 球员详情 → 累计数据 / 每90指标 / 百分位
                    ├→ 相似球员 → 位置画像 / 差异解释 / 双人对比
                    └→ 双人雷达 → Agent 对比
```

快照包含 562 个球员姓名和 20 支球队。12 条跨队附加记录代表同一球员在两家英超俱乐部的独立赛季片段，因此按俱乐部分别保留，并使用俱乐部限定的 slug，避免互相覆盖。

## 来源与可复现快照

| 项目 | 内容 |
|---|---|
| 数据集 | [Top 5 League Football Player Stats (2017-2025)](https://www.kaggle.com/datasets/emrey3lmaz/top-5-league-football-player-stats-2017-2025) |
| 固定版本 | Kaggle v1 |
| 上游更新时间 | 2026-04-18 |
| 上游说明 | 使用 `soccerdata` 从 FBref 收集 |
| 许可 | [CC0: Public Domain](https://creativecommons.org/publicdomain/zero/1.0/) |
| 应用范围 | English Premier League，源赛季 `2425`，应用赛季 `2024-25` |

`scripts/build_player_snapshot.py` 会读取固定 v1 ZIP，验证压缩包和 CSV 的 SHA-256，筛选英超 2024-25 行，规范化球队、位置、国籍和 slug，并校验以下不变量：

- 574 条球员—球队记录；
- 562 个球员姓名；
- 20 支球队；
- 400 条记录达到 450 分钟；
- 总出场时间 750,930 分钟。

运行中的应用只读取 `data/processed/kaggle_pl_players_2024_25.json`，不会联网下载或静默更新数据。

## 使用字段

快照仅保留产品需要的字段：球员姓名、俱乐部、位置、国籍、出生年份、出场、首发、分钟、进球、助攻、射门、关键传球、抢断、拦截和 xG。上游只提供出生年份时，详情页不会伪造完整生日；旧数据库中已知的完整生日和球衣号码在迁移时保留。

## 每 90 分钟计算

所有衍生指标由 FastAPI 后端统一计算：

```text
每90分钟指标 = 累计指标 × 90 ÷ 出场分钟
```

分钟数为 0 或原始值缺失时返回 `0.0`，其余结果保留两位小数。前端只负责显示，不重复计算业务指标。

当前包含进球、助攻、射门、关键传球、抢断、拦截和预期进球（xG）的每 90 分钟值。

## 分钟门槛与分页

球员中心默认使用 `450` 分钟门槛，对应 400 条合格记录；也支持 `0`、`1800` 和 `2700` 分钟。选择 `0` 可浏览全部 574 条记录，但低分钟样本的每 90 数据波动会更大。

列表由后端筛选、排序和分页，默认每页 50 条，API 单次最多返回 100 条。筛选条件变化后前端回到第一页，已选中的两名比较球员会跨页保留。

## 百分位范围

雷达图优先把球员与达到当前分钟门槛的同位置记录比较：

1. 同位置合格记录不少于 3 条：返回 `position_pool`。
2. 同位置合格记录少于 3 条：回退到全部合格记录，返回 `all_qualified_players`。
3. API 同时返回 `peer_count`，页面显示真实比较数量。

球员详情固定使用默认的 450+ 分钟池计算百分位。百分位只描述这份历史快照和当前门槛内的相对位置，不是官方排名、绝对能力评分或未来表现预测。

## API

```text
GET /api/players
GET /api/players/{slug}
GET /api/players/{slug}/similar
```

列表接口支持 `season`、`minimum_minutes`、`query`、`position`、`club_slug`、`sort_by`、`order`、`limit` 和 `offset`，并返回完整数据集、合格池、唯一姓名和转会附加记录数量，以及来源和许可元数据。

相似球员接口支持 `season`、`minimum_minutes` 和 `limit`，详细算法与限制见 [`SIMILARITY_SCOUT.md`](SIMILARITY_SCOUT.md)。自动化测试覆盖快照不变量、迁移保留、指标换算、筛选、排序、分页、详情、百分位范围、相似度排序、同名转会记录和参数错误。

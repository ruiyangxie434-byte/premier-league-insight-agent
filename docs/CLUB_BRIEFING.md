# Club Briefing Room：可打印球队情报简报

`v0.18.0` 新增 `/briefing` 页面与
`GET /api/clubs/{slug}/briefing` 接口。它不引入新的外部事实，而是把项目中已经通过测试的赛季状态、阵容透镜和候选信号组合成一份可复现的单队情报文件。

## 产品目标

此前的赛季状态、Squad Lens 与 Transfer Signal 分散在不同页面，适合专项探索，但不便于一次完成展示、汇报或保存。Club Briefing Room 增加统一交付路径：

```text
选择球队与分钟门槛
  → 赛季终态与主客场拆分
  → 阵容位置分钟与队内领跑者
  → 后卫 / 中场 / 前锋三条位置观察队列
  → 确定性摘要、来源与限制
  → 浏览器打印 / 保存 PDF
```

页面会在当前浏览器保存上次选择的球队，但不建立账号、不上传偏好，也不跨设备同步。

## API

```http
GET /api/clubs/liverpool/briefing?season=2024-25&minimum_minutes=900
```

参数：

| 参数 | 允许值 | 说明 |
|---|---|---|
| `slug` | 20 支球队的唯一 slug | 目标球队 |
| `season` | `2024-25` | 固定历史赛季 |
| `minimum_minutes` | `450`–`1800` | 同时约束阵容分析池与三条候选信号 |

响应的关键字段：

- `season_summary`：最终排名、整体 / 主场 / 客场记录、末五场和最长不败；
- `squad`：完整 Squad Lens 数据，包括位置组、队内领跑者与核心分钟；
- `recruitment`：DEF、MID、FWD 三条独立位置队列，各自包含需求百分位和首位历史统计候选；
- `headlines`：只由响应内数值生成的确定性摘要；
- `sources` 与 `limitations`：打印输出仍保留的数据合同。

## 计算口径

### 赛季状态

- 只读取 OpenFootball 固定提交中的 2024–25 完整 380 场最终比分；
- 单队必须有 38 场记录和对应最终积分榜记录；
- 末五场按真实开球日期排序；
- 主客场每场积分为各 19 场积分除以场次。

### 阵容与候选

- 统一使用用户选择的最低分钟门槛；
- 阵容位置占比和前五负荷仍沿用 Squad Lens 公式；
- DEF、MID、FWD 分别调用同一 Transfer Signal 计算，不把三个位置的信号分互相比较；
- 每条队列只在简报中展示首位候选，完整候选、提升项与权衡项仍在 `/transfer` 页面查看；
- 门将因缺少扑救、失球和阻止进球等专属字段，不进入候选队列。

## League Copilot

第九个受控工具为：

```text
build_club_briefing(club, season, minimum_minutes)
```

“生成利物浦的完整球队情报简报”等问题会直接调用该工具，而不是让模型分别拼接多个自由回答。后端仍会规范化球队 slug、限制赛季和分钟枚举，并把赛季、阵容与位置观察证据一并返回。

## 打印与边界

页面使用浏览器原生打印，可选择“另存为 PDF”。打印样式会隐藏导航与筛选控件，保留球队、赛季、分钟门槛、来源和限制。

简报不是实时球探系统，也不是未来预测。它不包含：

- 当前名单、伤病、停赛与比赛日可用性；
- 实时转会、身价、合同、工资与成交概率；
- 球队战术职责、阵型、控球率或完整 xG；
- 未来赛果、球员表现或签约成功率预测。

## 测试

测试覆盖：

- 三类快照能被同一接口正确组合；
- 分钟门槛同时传递到阵容和候选模块；
- 位置观察队列固定为 DEF、MID、FWD；
- 未知球队、非支持赛季与非法分钟门槛会被拒绝；
- Copilot 能通过第九工具返回规范化参数、证据、链接与限制。

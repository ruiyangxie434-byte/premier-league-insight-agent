# Squad Lens：阵容结构与队内贡献

`v0.16.0` 新增 `/squad` 页面与 `GET /api/clubs/{slug}/squad-lens` 接口。它把现有 2024-25 球员—俱乐部快照汇总为单队阵容结构，不引入新的数据源，也不生成实时名单或比赛预测。

## API

```http
GET /api/clubs/liverpool/squad-lens?season=2024-25&minimum_minutes=450
```

参数：

- `slug`：数据库中的球队 slug；
- `season`：当前只支持有记录的 `2024-25`；
- `minimum_minutes`：`0–4000`，默认 `450`。

当球队不存在，或当前门槛没有合格记录时返回 `404`；非法门槛返回 `422`。

## 计算口径

每条输入记录代表“球员 × 俱乐部 × 赛季”。转会球员在不同俱乐部的分段不会合并。接口先按球队和赛季选取记录，再应用分钟门槛。

- `record_total`：该队赛季快照的全部记录数；
- `qualified_total`：达到分钟门槛的分析池记录数；
- `position_groups`：按 `GK / DEF / MID / FWD` 汇总记录、分钟、进球和助攻；
- `minutes_share`：位置或球员分钟 ÷ 分析池全部球员分钟；
- `top_five_minutes_share`：出场分钟前五名之和 ÷ 分析池全部球员分钟；
- `leaders`：出场时间、进球、助攻、关键传球与“抢断 + 拦截”的队内总量领跑者；
- `core_players`：按出场分钟排序的前八条记录。

所有占比保留一位小数。领跑指标相同时，优先出场分钟更多的记录，再按姓名稳定排序。

## 解释边界

- 位置分钟占比描述赛季记录结构，不等于阵型、站位或战术角色；
- 球员进球和助攻只汇总达到门槛的记录，不等于球队赛季进球；
- 前五分钟占比只描述分析池内的出场负荷集中度，不代表阵容质量；
- 快照不是当前实时名单，不包含伤病、合同、转会动态或实时状态；
- 当前球员数据缺少门将扑救、零封和失球字段，因此不输出门将专属评价。

## Copilot 工具

同一能力注册为 `analyze_club_squad`。工具只接受白名单赛季与 `0 / 450 / 900 / 1800` 四档门槛，并返回分析池、位置结构、领跑者、页面链接和限制说明。本地路由可识别“阵容”“位置贡献”“队内核心”“出场负荷”等问题；千问只负责选择工具和组织已返回的证据。

# Demo dataset boundaries

开发数据库的初始化数据维护在
`backend/app/database/seed.py`，并按用途标记：

| `source_kind` | 范围 | 含义 |
|---|---|---|
| `reference` | 20 支球队与球场 | 2024-25 赛季地理参考数据 |
| `historical` | 20 队最终积分榜 | 2025-05-25 的完整历史快照 |
| `kaggle-fbref` | 574 条球员—球队赛季记录 | Kaggle v1 的 2024-25 CC0 历史快照 |
| `openfootball` | 380 场 2024-25 最终比分 | OpenFootball CC0 完整赛果快照 |
| `open-data` | 1 场比赛与 28 次射门 | StatsBomb 公开历史事件快照 |

这套数据用于：

- 验证球队、球员、赛季统计与积分榜之间的关系。
- 验证 20 个球场坐标可以被地图接口读取。
- 为前端搜索、排序、加载、错误和空状态提供稳定输入。
- 为 Agent 的工具调用、每 90 分钟换算、动态权重和证据链提供固定历史数据。
- 为球员榜筛选、排序、详情页和单人/双人雷达图提供稳定输入。
- 验证 574 条记录、562 个姓名、20 支球队、12 条跨队附加记录和 400 条 450+ 分钟记录。
- 验证同位置记录不足 3 条时，百分位范围会安全回退到全部合格记录。
- 让自动化测试在无网络环境下稳定运行。
- 验证旧版 6 队 SQLite 数据库可以幂等升级至 20 队。
- 验证公开事件快照可幂等写入比赛表，并生成射门图、xG 对比和进球时间线。
- 验证完整赛果可幂等写入比赛表，并与最终积分榜逐队对账、生成 38 轮走势和末五场状态。
- 验证 Agent 分析结果可保存、恢复并形成父子追问链；分析快照不是新的足球数据来源。

2024-25 最终积分榜、380 场赛果和球员指标都不是当前赛季实时数据。比赛事件来自 2003/2004 历史赛季，不与 2024-25 球员快照混合计算。
完整来源、快照日期和更新原则见 `docs/DATA_SOURCES.md`。
